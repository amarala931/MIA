# MIA

Repositorio de materiales del módulo **Modelos de Inteligencia Artificial**, perteneciente al Curso de Especialización en Inteligencia Artificial y Big Data. Incluye una aplicación web para explorar algoritmos y un cuaderno práctico de aprendizaje supervisado.

## Contenido

```text
MIA/
├── IA-lecciones-interactivas/   Aplicación web educativa de algoritmos de machine learning
└── lecciones_google_colab/      Cuadernos y prácticas para Google Colab
    └── UD1/
        └── entrenamiento_supervisado.ipynb
```

### Aplicación de lecciones interactivas

[IA-lecciones-interactivas](./IA-lecciones-interactivas/) es una aplicación React que combina explicaciones, visualizaciones interactivas y ejemplos de código Python con scikit-learn. Incluye laboratorios de regresión lineal y polinómica, clasificación KNN y clustering K-Means, además de una sección de temas previstos.

Consulta su [README](./IA-lecciones-interactivas/README.md) para conocer sus requisitos, comandos de desarrollo y opciones de compilación.

### Cuadernos de Google Colab

[lecciones_google_colab](./lecciones_google_colab/) reúne prácticas en notebooks. El material disponible corresponde a la unidad 1 y explora la regresión lineal simple con el conjunto de diabetes incluido en scikit-learn.

Consulta el [README de los cuadernos](./lecciones_google_colab/README.md) para ver el contenido de la práctica y abrirla en Colab.
